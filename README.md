# BiliLive Assistant

**跑在自己电脑上的 B 站直播机器人**

不用写代码、不用装环境，下载双击就能用。
签到、欢迎、答谢、播报、定时广告……直播间的杂活全交给它，

## 它能做什么

### 直播间互动

- **每日签到** —— 观众发弹幕签到，机器人自动登记并发放积分或星光
- **进房欢迎** —— 观众进入直播间自动欢迎
- **感谢关注 / 分享** —— 观众点关注、分享直播间，自动发弹幕致谢
- **礼物答谢** —— 收到礼物、上舰、醒目留言（SC）、盲盒自动发弹幕致谢，可设起始感谢的电池门槛，同一时段的礼物能合并成一条
- **PK 播报** —— 开始 PK 自动播报，播报内容里能带上与对手的历史交手战绩
- **弹幕自动回复** —— 设置关键词和回复内容，命中即自动回复；可配置安全词避免误触发，并支持自动禁言
- **禁言赎金** —— 被自动禁言的观众，赠送指定数量的电池即可自动解禁，惩罚变成玩法
- **定时广告** —— 设置好内容和时间间隔，机器人定时发广告弹幕，支持多条内容随机轮播

### 积分体系与商城

- **双币种** —— 星光和积分两套独立货币，商品可以用其中任意一种定价
- **多种发放渠道** —— 签到、送礼消费电池（可按倍率换算）、开通大航海（舰长 / 提督 / 总督三档分别配置），每种渠道都能单独选择发星光还是发积分
- **观众端商城** —— 观众用手机打开就能逛：商品搜索与分类、商品详情、下单、收货地址、我的订单、余额与明细
- **虚拟与实物商品** —— 虚拟商品下单即完成，实物商品走收货地址和物流流程，后台可查看订单并推进发货状态
- **后台商品管理** —— 商品支持多规格 SKU、分规格设置库存、商品图组、标签与排序

### 数据记录与分析

开启监听后自动记录，全部数据只存储在你自己的电脑上：

- **弹幕记录** —— 按房间、时间筛选查看
- **礼物榜** —— 礼物明细与总数量、总金额统计
- **盲盒记录** —— 单独统计盲盒，对比送出价与爆出价
- **PK 战绩** —— 每场 PK 的对手、结果与数据
- **观众分析** —— 观众列表、月度活跃、单人弹幕明细，以及弹幕词云
- **直播场次** —— 按开播场次归档，方便回看

## 为什么选它

- **零门槛**：下载对应系统的安装包，双击启动即可运行，不需要安装任何环境
- **数据安心**：弹幕、礼物、积分、订单全都存在你自己的电脑上，不会上传到任何第三方服务器
- **可视化配置**：全部功能在网页后台里点点选选就配好了，不需要碰任何配置文件和代码
- **玩法闭环**：从弹幕互动、积分发放到商城兑换和订单发货，一条链路都在同一个后台里
- **全平台支持**：Windows、macOS、Linux 都有对应的安装包

## 快速开始

1. **下载安装包**：前往 [Releases](https://github.com/zxc7563598/bilibili-live-assistant/releases) 页面，下载对应系统的安装包
2. **双击启动**：解压后双击运行程序（因项目启动后会创建配置以及数据文件，后续运行依赖产生的文件，因此建议将程序移动到单独的目录后再运行）
3. **扫码登录**：浏览器打开 http://localhost:25443 ，扫码登录你的 B 站账号
4. **填写房间号，开启监听**：在后台填入你的直播间房号，打开监听开关，搞定

> [!NOTE]
> 机器人运行期间需要保持电脑开机并联网，退出程序即停止工作。

## 观众怎么用积分商城

商城是挂在机器人上的一个网页，程序跑起来之后，地址就是 `http://你的访问地址/shop`。后台的「App 配置」页里会直接显示这个地址，可以一键复制。

观众用**自己的 B 站 UID** 登录商城，第一次登录时设置一个密码就能用。

> [!IMPORTANT]
> 默认是**本地模式**，商城只有你本机能访问，手机扫同一个二维码是打不开的。
> 要让观众用手机访问，需要让程序跑在一个外网能连到的地址上（**服务模式**），然后到「App 配置」里把站点名称、图标这些信息填上，观众就能把商城「安装」到手机桌面，像普通 App 一样点开即用。

服务模式的部署方式可以看 [官方文档](https://hejunjie.life/danmusuite/local/provide-service)，文档里讲了怎么打包、传到服务器并用 systemd 常驻运行。

## 常见问题

**机器人需要一直开着电脑吗？**

需要。机器人是运行在你电脑上的程序，电脑关机或程序退出后就会停止工作，商城也一并无法访问。

**数据存在哪里？会泄露吗？**

所有数据（登录状态、弹幕记录、积分、订单、配置等）都保存在你的电脑本地，不会上传到任何第三方服务器。

**支持哪些系统？**

Windows、macOS、Linux 均有对应的安装包。

**需要提前安装什么环境吗？**

不需要。安装包已内置运行所需的一切（包括数据库），下载解压后直接双击运行。

**直播间房号在哪里看？**

打开你的直播间网页（live.bilibili.com），网址后面的那串数字就是房号。

**观众说登录商城提示「当前账号并未注册」？**

商城账号是跟着直播间观众走的。观众需要先在你的直播间被机器人记录过（发过弹幕、送过礼物或签过到），用同一个 B 站 UID 才能登录。另外后台「App 配置」里如果关闭了注册开关，新观众也无法自助注册。

**星光和积分有什么区别？**

两套互相独立的货币，用途完全由你决定——比如签到发积分、上舰发星光，商品也分别用其中一种定价。具体怎么搭配看你的直播间玩法。

**能部署到服务器上吗？**

可以。项目本身是一个 Web 服务，一键安装包默认是本机访问；把它按**服务模式**部署到自己的服务器上，就可以作为网站运行，支持观众远程访问。具体步骤见 [官方文档](https://hejunjie.life/danmusuite/local/provide-service)。

**积分商城需要 HTTPS 吗？**

不强求。HTTP 也能正常用，只有开启「强制请求加密」时才要求全站 HTTPS，纯 HTTP 部署保持默认关闭即可。
